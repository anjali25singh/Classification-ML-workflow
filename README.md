# Classification ML Workflow

Step-by-step implementation of a classification ML workflow using scikit-learn on the Breast Cancer dataset.

## Workflow Steps
1. Problem Understanding
2. Data Collection
3. Data Cleaning
4. Data Preprocessing
5. Exploratory Data Analysis (EDA)
6. Feature Engineering
7. Train-Test Split
8. Model Selection
9. Model Training
10. Hyperparameter Optimization
11. Model Evaluation
12. Model Deployment

## Tech Stack
Python, pandas, scikit-learn, joblib
